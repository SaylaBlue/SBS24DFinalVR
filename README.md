My project was originally supposed to be a fully developed horror game about writer's block, but unfortunately, time did not permit.  This project is a writer coming home after a long day of work to do what he loves, watch a film for inspiration to help him write his next best seller or film. This film did not help; instead of leaving him with inspiration, it gave him writer's block. Now he must destroy his blockage before it defeats him.  In this project, you visit 3 different sets, outside the house, inside the house (with a kitchen, bathroom, bedroom, living room, and office), and the origin of writer's block, which in this case is a spooky forest.  The additional skill I put into this project was adding a video; the player clicks a remote, making the TV play a short montage I made. I also had to create smoke VFX for the chimney and learn how door hinges work. Unfortunately, the door hinges are a bit glitchy due to the mesh used.   

The Key challenge I overcame was honestly making the house. I had to download so many assets as well as put every object down separately, which makes sense. Additionally, I created new materials to have a nice theme for the house.
